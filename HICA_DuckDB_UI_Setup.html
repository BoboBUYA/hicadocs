Explore the Silo lake with DuckDB

HICA training · a browser notebook where you type SQL and read the lake files directly.

Before you start

You need the HMIS platform set up (the project folder with docker-compose.yml) and the dbt virtual environment ~/venvs/hmis-dbt, which already contains DuckDB. Open the project folder in VS Code and use the WSL terminal.

One-time setup

1Create the file. In the VS Code Explorer, click the New File icon, name it duckdb_ui.py and keep it in the project folder, next to prefect.yaml.
2Paste this into it and save with Ctrl+S. 
import duckdb

con = duckdb.connect()
con.sql("INSTALL httpfs; LOAD httpfs;")
con.sql("""
CREATE SECRET silo (
  TYPE s3,
  KEY_ID 'minioadmin',
  SECRET 'minioadmin',
  ENDPOINT 'localhost:9100',
  URL_STYLE 'path',
  USE_SSL false
)
""")
con.sql("CALL start_ui()")
input("DuckDB UI is running. Press Enter here to stop it.\n")

What it does: starts DuckDB, adds the extension that reads S3-style storage, saves the Silo address and login, and opens the browser interface.

Every time you want to use it

1Start the services (skip if they are already running): 
docker compose up -d
2Activate the dbt environment: 
source ~/venvs/hmis-dbt/bin/activate
3Run the file from the project folder: 
python duckdb_ui.py

You may see xdg-open: not found. Ignore it, it only means WSL could not open the browser for you.

4Open the interface. In your Windows browser go to http://localhost:4213 and click Or give me an empty notebook.
5Run SQL. Type in a cell and press Ctrl+Enter. Start with: 
select * from glob('s3://hmis-datalake/**') limit 50;
6Stop it. Click the terminal and press Enter.

Handy queries

Count files in each layer of the lake:

select split_part(file, '/', 4) as layer, count(*) as files
from glob('s3://hmis-datalake/**')
group by all order by 1;

See the columns of a Parquet file (use a path you found with glob):

describe select * from read_parquet('s3://hmis-datalake/staging/dhis2/stg_dhis2__data_elements.parquet');

Read the raw landing JSON, one row per data value:

select
  dv->>'dataElement' as data_element,
  dv->>'period'      as period,
  dv->>'orgUnit'     as org_unit,
  dv->>'value'       as value
from (
  select unnest(dataValues) as dv
  from read_json_auto('s3://hmis-datalake/landing/dhis2/data_values/dataset=staffing/**/*.json.gz')
)
limit 20;
Good to know. Keep the terminal open while you use the notebook. The login minioadmin / minioadmin is for local teaching only. If you see a connection error, check that the Silo container is running with docker compose ps. If start_ui is not found, run pip install -U duckdb in the activated environment.

Clone the repo, run setup (optionally without data), then keep the worker terminal open for scheduled runs.Clonez le dépôt, lancez l’installation (éventuellement sans données), puis gardez le terminal du worker ouvert pour les exécutions planifiées.Clone o repositório, execute a instalação (opcionalmente sem dados) e mantenha o terminal do worker aberto para as execuções agendadas.

# 1. PowerShell (Windows)
$ wsl --install -d Ubuntu

# 2. Ubuntu terminal
$ sudo apt install git curl python3 python3-venv

# 3. Clone and start
$ git clone https://github.com/mkwarah/hmis_ingestion.git ~/hmis_ingestion
$ cd ~/hmis_ingestion
$ ./setup.sh
  # add --skip-data to install without loading data
$ ./start_worker.sh
  # keep this terminal open for scheduled runs
